# Recamán Next-Move Predictor

This Space demonstrates the finite-horizon previous-bit baseline measured by
the Recamán obstruction research repository.

It predicts the next obstruction bit, not the location of rare phase slips or
which values remain permanently missing. The displayed probabilities come from
the saved 10-million-step empirical run and are not an asymptotic proof.
